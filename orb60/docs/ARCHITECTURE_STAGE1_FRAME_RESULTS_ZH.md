## 新瓶颈

压力帧总 AXI 流量仍为 8,462,552 bytes。高首读延迟时，各层描述子均慢于下一层
图像；raw / blur patch 端口分别发出 29,417 / 35,169 个 AR 请求，实际最大
outstanding 均为 2，受限配置的平均值仅 0.558 / 0.678。
相应 read_pending 为 1,569,728 / 1,883,488 拍；它们可并行，不能相加为整帧独占停顿。
该受限配置聚合服务槽利用率为 34.3%；双 beat 高延迟配置为 18.3%。
这些数据表明短请求的返回延迟及串行取数限制了吞吐，继续增加 BRIEF 比较器
不能直接消除等待，单纯 4PPC 也会留下描述子主瓶颈。

Profile 绑定包含 203 个信号、42 个 FIFO。原始 blocked 指标由 FIFO 引脚握手
表达式生成；HLS 可能已在这些引脚之前抑制请求，当前零 blocked 观察值不能用来
宣称没有背压。actor busy 包含等待；阶段瓶颈同时依据逐层耗时、端口等待和水位判断。
